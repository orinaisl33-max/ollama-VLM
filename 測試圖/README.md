## 怎麼用

1. 開啟 `run.command`，選已安裝的圖文模型，按「附加圖片」選本資料夾的一張圖。
2. 先問可核對的問題，例如左右顏色或特定物件位置；不要把模型敘述當成既定答案。
3. 開啟「框選／匯出」，輸入一種目標，例如「人物」，上限先設 1–3。留空搜尋時預設上限為 10。
4. 逐框預覽完成後，核對位置、漏框及重複；人工修正後再匯出。想比較同圖不同模型，記錄模型、目標、上限及耗時。

「機器人視角」圖片原本就含 Fall 0.97、骨架與分割圖等覆蓋內容；它們是圖片的一部分，不是本程式推論出的分數、姿態或可靠跌倒判斷。建議先用沒有這些覆蓋內容的圖測試。

此資料夾現在是公開示範目錄，請不要把私人圖片、錄音或個人資料放入；私人測試請用被忽略的 `private/`。
