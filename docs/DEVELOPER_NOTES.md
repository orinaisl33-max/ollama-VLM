Python 3.11 + PySide6 + Ollama 的本機文字／圖片聊天工具，配置以 MacBook Air M2、8GB 統一記憶體為起點。

## 啟動

在 Finder 雙擊 `run.command`。腳本會檢查專案 `.venv`，必要時啟動 Ollama，再開啟介面。啟動後會非同步確認服務及所選模型是否已安裝；服務恢復後可按「檢查服務」更新狀態。

此電腦已安裝 Python 3.11、PySide6、Ollama 與均衡模式使用的模型。模型位於 `~/.ollama/models`，與虛擬環境分開。

## 從零安裝

先安裝 [Ollama](https://ollama.com/download/mac) 與 Python 3.11 以上版本，再在專案目錄執行：

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
ollama pull qwen3.5:2b
./run.command
```

如已透過 Ollama App 啟動背景服務，無須再執行 `ollama serve`。Qt 套件鎖定為目前驗證過的版本，請勿將其他 Python 環境的套件混入本專案。

## 操作

- Enter 傳送；Shift + Enter 換行，中文輸入法組字時不攔截 Enter。
- 示範入口只填入草稿，檢閱後再傳送。影像示範需先附加圖片。
- 圖片支援靜態 PNG／JPEG／WebP，一次一張，限制 20MB、1600 萬像素；傳送前套用方向資訊並將最長邊縮至 1024 像素，不放大小圖。
- 生成時可停止；停止、逾時、失敗均保留輸入與圖片，未完成回覆不加入後續歷史。
- 新對話清空目前畫面及圖片，不刪除已存紀錄；各對話的文字草稿獨立保存。切換運算模式會建立新對話。
- 圖片只送入當次請求；再次觀察同一圖片必須重新附加。歷史僅保留文字。
- 模型串流期間先顯示文字，回覆完成後以 Markdown 呈現標題、粗體、清單與表格；歷史回答也使用相同排版。禁止 HTML、外部資源載入與連結導覽。閱讀較早訊息時，串流不會強制捲回底部。

## 穩定性與資源限制

單次問題上限 4000 字，歷史最多三輪且與當前問題合計上限 8000 字；按完整問答組刪除舊資料。字數限制不是精確 token 計數，4096 context 內的實際可用內容會受圖片與語言影響，Ollama 仍可能裁切過長上下文。

最多生成 1024 tokens，達長度上限時顯示提示；單次回覆最多接收 32000 字。聊天顯示紀錄有字數與段落上限，長時間使用會移除最舊的顯示內容。網路閒置超過 180 秒、整體請求超過 10 分鐘會中止。串流單行限制 1MB，總資料限制 16MB；異常格式立即中止。關閉視窗會斷開回呼、停止計時器並取消未完成請求。

聊天 API 固定使用 `127.0.0.1:11434`、不經系統 HTTP 代理且不跟隨重新導向。沒有雲端推論、影片或圖片生成功能；語音輸入使用本機 Whisper，語音輸出使用 macOS 本機 TTS。對話與圖片不寫入應用程式日誌；Ollama 自身的日誌及設定另由 Ollama 管理。

## 驗證與維護

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/ruff check main.py labchat tests scripts
.venv/bin/ruff format --check main.py labchat tests scripts
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -v
```

回歸測試只建立本機模擬 HTTP 伺服器，不需要網路下載或 Ollama 模型。選擇性實機測試：

```sh
.venv/bin/python scripts/smoke_local.py
```

實機測試使用固定文字及合成的左右雙色圖片，走正式 Qt／圖片處理流程。程式檢查請求完成，模型回答的語義仍須檢閱測試輸出；這不是模型準確率或效能基準。

應用程式日誌位於 `.logs/application.log`，每份最多約 1MB，保留兩份舊檔。由啟動腳本建立的 Ollama 日誌位於 `.logs/ollama.log`，下次由腳本啟動服務時保留前一份。若使用 Ollama App 啟動服務，請查看其自身日誌。服務狀態只代表最近一次檢查，並非持續監控。

功能驗證與限制見 `INSTALLATION.md`。模型回答仍可能出錯，圖片中的小字、複雜圖表與模糊內容尤其需要核對。

## 語音回覆（macOS）

可選「朗讀關閉」、「分段朗讀」或「完成後朗讀」，預設關閉。分段模式在完整句子就緒時依序朗讀，不等整份回答；完成模式只處理成功完成的最新回答。完整回答仍可手動按「朗讀回覆」。朗讀中可按「停止朗讀」；送出下一個問題、新對話、切換模式及關閉視窗均會停止前一次播放。

「語音設定」可選取系統已安裝的中文聲音、調整語速並試聽。預設優先選取 Meijia（美佳／台灣中文）；列出的聲音不代表都是增強或高自然度版本，請以試聽判斷。數值為 macOS 的語速參數，不是中文每分鐘字數。

若要下載額外音色，依 [Apple 官方說明](https://support.apple.com/guide/mac-help/change-the-voice-your-mac-uses-to-speak-text-mchlp2290/mac) 到系統設定的輔助使用語音朗讀設定下載，完成後在本工具按「重新整理」。工具不會自動下載聲音，也不會使用雲端 API。此版本未接入雲端 TTS；Mac 語音輸入使用本機 Whisper，見 VOICE_INPUT.md。

TTS 與 Ollama 分開執行，使用系統 `/usr/bin/say`，不另載入大型神經語音模型。文字透過標準輸入傳送，不放進程序命令列或寫成文字暫存檔。一般朗讀直接播放，沒有保存音訊。程式碼區塊會略過並提示，Markdown 連結與格式轉成適合朗讀的文字；過長內容最多朗讀約 8000 字並提示截短，單次播放上限 10 分鐘。程式會停止自己啟動的語音程序，不影響其他應用程式的聲音。

語音模式、音色與語速會保存為本機偏好，重啟後還原；還原設定不會自動開始播放或錄音。麥克風輸入為另一個獨立功能，見 VOICE_INPUT.md。語音自動化測試使用模擬程序，不會在跑測試時發聲。

語音設定視窗關閉時會停止試聽；一般回答的朗讀仍可使用主視窗停止。重新整理聲音清單時暫停播放，完成後才接續自動朗讀；無可用聲音時會關閉自動朗讀。服務檢查另有 10 秒總時間上限，失敗後可重試。

## 圖片框選與處理指示

生成或定位進行中會顯示旋轉指示，停止、失敗、逾時或關閉時停止動畫。

附加圖片後按「檢視／框選」，可檢視圖片、輸入目標並要求「AI 建議框」，或直接拖曳手動畫框。清單可選取、改名與刪除；位置可用調整模式移動／縮放，也可刪除後重畫。支援 PNG 標註圖及 JSON 座標資料匯出，採原子寫入。圖片預覽／匯出使用前處理後的大小（最長邊 1024），JSON 記載該尺寸，bbox 為 0–1000 的相對 xyxy 座標。

AI 框為模型定位估計，可能漏認、重複或標錯位置，不提供偽造信心分數；群組框也不能用來推算水果顆數。系統會保留人工框，重新執行 AI 定位時只更新 AI 框，最多 60 個。Ollama 後端若不支援指定結構格式，會嘗試一次相容請求；資料無效或請求失敗時保留原有標註。

最近選取的圖片與本次標註會暫留於記憶體，分析後仍可開啟，並不自動隨後續聊天傳送。新圖片、新對話或關閉程式會清除未保存的暫存；可選擇本機保存或匯出，詳見新版功能指南。帶入新圖片時不沿用舊對話中的視覺結論，以減少錯誤累積。

水果案例的實測限制與正確性核對見 `artifacts/水果圖回答核對.md`。預設 2B 模型仍會漏認與誤判，提示詞改善不代表計數可靠。

## 安全複查
